# SolarMind Frontend

Single Page Application (SPA) built with React 18, Vite, Recharts, and Lucide React for solar monitoring and diagnostics.

## Features
- Real-time generation overview and power curves (Actual vs. Expected).
- Diagnostic center highlighting fault alerts (Shading, Soiling, Inverter clipping, String disconnection).
- Energy & financial loss estimation dashboard.
- Computer vision photo upload interface for panel defect and soiling inspection.
- Clean, high-contrast dark/light responsive interface styled with Vanilla CSS tokens and micro-animations.

## Prerequisites
- Node.js 18+
- npm 9+

## Local Installation & Setup

1. **Navigate to the frontend folder:**
   ```bash
   cd frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Development Server:**
   ```bash
   npm run dev
   ```

4. **Open in Browser:**
   - App URL: `http://localhost:5173`

## Running Tests
```bash
npm run test
```
